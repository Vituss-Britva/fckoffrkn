# FckoffRkn

Приложение для Android и Windows с рабочими зеркалами казино, букмекерских контор и покер-румов. Ссылки обновляются автоматически — рабочий вход всегда под рукой, искать новое зеркало вручную не нужно.

## Зачем это нужно

Официальные домены казино и БК регулярно блокируют, а найти актуальный адрес через поисковики и мессенджеры с каждым разом сложнее. FckoffRkn решает эту проблему: приложение хранит каталог проверенных площадок и само подставляет рабочую ссылку, если старый адрес перестал открываться.

## Что в каталоге

- **Казино** — популярные и новые лицензированные площадки.
- **Букмекерские конторы** — зарубежные БК с приёмом ставок на спорт.
- **Покер-румы** — с рейкбеком и живыми турнирами.

## Как начать

1. Скачайте APK для Android или установщик для Windows по ссылкам ниже.
2. Разрешите установку из неизвестных источников — стандартное системное предупреждение.
3. Откройте приложение, выберите раздел каталога и переходите по рабочей ссылке.

Регистрация в самом приложении не нужна.
